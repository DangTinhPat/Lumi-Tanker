## Yaw smoothing follow-up

With yawhold enabled, the StandUp damper, LQR yaw-rate feedback and drive
heading loop now use a shared 25 ms gyro low-pass. While no turn is requested,
`rate - 0.015*tanh(rate/0.015)` smoothly attenuates near-zero noise; deliberate
turns retain the filtered rate without this attenuation. Invalid or >10 ms
samples clear filter state; disable and inactive states reset it. Pitch input
and command shaping are unchanged. The LQR wheel deadband push now acts on
common speed only in the enabled path, avoiding extra tanh gain on tiny
differential yaw commands around zero. StandUp retains its 50 ms downstream
filter and bounded correction slew.

Three focused host tests and the candidate firmware build pass (RAM 166376 B,
flash 1509385 B). Synthetic 20 Hz, 0.01 rad/s gyro-noise energy after filtering
is <1% of raw, with steady deliberate-turn response preserved. All 18 StandUp
differential plant cases pass (worst integrated yaw ratio 0.7246); all 36
drive cases still pass. Filtering adds feedback lag and attenuates very slow
unwanted rotation, so reduced physical vibration is pending robot logs.

## Behavior

Existing yaw-rate feedback (yawkp=0.6) remains unchanged. A new outer heading
loop integrates bias-corrected gyro yaw while driving straight, then adds an
equal/opposite wheel-speed correction. A left obstruction producing positive
yaw during forward travel requests more left speed and less right speed;
signs reverse correctly for reverse travel and right obstructions. This is a
relative heading P / inner rate P cascade with bounded integration, referencing
Astrom & Rundqwist, "Integrator Windup and How to Avoid It", ACC 1989.
No upstream implementation was copied.

The extra command increases gradually, within remaining wheel-speed headroom.
It preserves the pitch controller's mean wheel command. Limits are initial
engineering bounds, not measured motor ratings or validated curb dimensions:

- heading gain 4 /s, stored angle error <=0.15 rad;
- extra speed <=3 rad/s per wheel (0.12 m/s at radius 0.04 m); angle/gain
  limits currently constrain the achievable maximum further;
- increasing correction <=4 rad/s²; normal decreasing correction <=12 rad/s²;
- aggregate time with correction/target >0.1 rad/s <=1.5 s per straight-drive
  episode, then unwind and latch off until stop/turn/safety reset;
- drive command magnitude must exceed 0.04 m/s and yaw request <=0.01 rad/s;
- virtual-pitch error <0.08 rad and rate <0.5 rad/s, no held/lifted state,
  stand-up recovery-pose hold, hop or hop arming; dt <=10 ms.

A stop, deliberate turn, direction reversal, safety violation or disabled
feature clears the relative heading and extra command immediately. This
safety reset takes priority over the normal release slew. Saturation prevents
outward angle integration; no new wheel ceiling is introduced. Existing sensor
fault/disable behavior continues to own the final output. The added code uses
constant storage and bounded arithmetic, with no parsing or allocations.

This does not identify physical contact or guarantee that a wheel is obstructed.
A gyro-detected unwanted turn is the trigger; slip, uneven traction or external
pushes can also produce it. If both wheels stall without yaw, this feature
will not initiate a climb. It sends speed requests, not direct torque/current
commands. It is intentionally symmetric: boosting one side also restrains the
other so pitch's common speed demand is preserved.

Yaw bias learning remains active in quiet Balancing windows: the wheel encoder
differential provides the yaw-rate reference, while measured translation and
differential wheel yaw must both be near zero. This lets the controller follow
slow gyro-Z temperature drift while stopped. Significant turns and wheel slip
keep the learner gated by the existing `quiet` and residual-rate bounds. A
6-axis IMU still provides no absolute compass reference, so this is rate-bias
correction, not absolute heading. The near-upright gyro-Z approximation is
retained from the existing yaw-rate loop; no frame or geometry is changed.
Firmware half-track remains 0.1545 m and radius 0.04 m. The documented CAD track
conflict is not recalibrated by this change.

## Selection and diagnostics

Core and regular/single-loop builds default off. The selected
`esp32-s3-v3-1840-roll` miniforce candidate defaults on, alongside standprep.
`SET yawhold 0|1` requires Idle (DISABLE first). Reset reloads the build default.
GET reports enable/gain/limits. Separate 5 Hz `YH` lines report stored angle
error, signed extra wheel speed (positive adds right/subtracts left), and
budget lockout. No GUI replacement, motor command, OTA, commit or push was
performed in this implementation task.
